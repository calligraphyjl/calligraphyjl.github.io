03. 项目展示

猜数字小游戏

Python · 单文件

电脑随机生成 1-100 之间的数字，用户输入猜测数字，程序提示“大了”或者“小了”， 直到猜中，最后统计一共猜测多少次。单文件 Python 代码，可以使用命令行运行。

  • 运行 · python guess_number.py
  • 依赖 · 无（Python 3.6+）
import random

def main():
    """猜数字小游戏：随机数在 1-100 之间，直到猜中为止。"""
    answer = random.randint(1, 100)
    count = 0
    print("我已经想好了一个 1-100 之间的整数，来猜猜看吧！")

    while True:
        guess = input("请输入你的猜测（1-100）：").strip()

        # 输入校验：必须是 1-100 的整数
        if not guess.isdigit():
            print("请输入 1-100 之间的整数。")
            continue
        guess = int(guess)
        if not 1 <= guess <= 100:
            print("范围是 1-100，请重新输入。")
            continue

        count += 1

        if guess > answer:
            print("大了")
        elif guess < answer:
            print("小了")
        else:
            print(f"猜中啦！答案就是 {answer}，你一共猜了 {count} 次。")
            break

if __name__ == "__main__":
    main()

# 猜数字小游戏（Guess the Number）

一个用 Python 编写的命令行小游戏：程序随机生成 1-100 之间的整数，玩家反复输入猜测值，程序返回“大了 / 小了”，直到猜中并统计猜测次数。

## 功能

· 随机生成 1-100 的目标数字
· 输入非法时给出友好提示，不消耗猜测次数
· 每次猜测实时反馈“大了 / 小了”
· 猜中后统计总次数

## 运行方式

需要 Python 3.6 及以上版本，无需安装第三方依赖。

python guess_number.py

## 示例

我已经想好了一个 1-100 之间的整数，来猜猜看吧！
请输入你的猜测（1-100）：50
小了
请输入你的猜测（1-100）：75
大了
请输入你的猜测（1-100）：63
猜中啦！答案就是 63，你一共猜了 3 次。

## 可拓展方向

· 增加难度等级（改变数字范围）
· 限制最大猜测次数
· 记录历史最佳成绩
